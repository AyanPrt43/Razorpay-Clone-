# 💳 Razorpay Clone

A modern **Razorpay Landing Page Clone** built using **HTML and Tailwind CSS**.  
This project recreates the UI and experience of Razorpay's payment platform with a clean, responsive, and professional design.

## 📌 Project Overview

This project is a frontend clone of Razorpay's website interface created to practice and demonstrate:

- Modern UI development
- Responsive web design
- Tailwind CSS utility-first styling
- Component-based page structuring
- Professional landing page design

The website focuses on creating a payment gateway platform interface with sections for payments, banking solutions, products, features, and pricing.
